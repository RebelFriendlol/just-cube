# justcube

justcube is a small browser tool for drawing practice.

It shows a 3D cube that you can rotate and view from different angles. The idea is to make cube and form practice quick and easy without opening a full 3D program.

## Features

- rotate the camera around the cube
- reset camera
- default view presets
- show / hide grid
- ghost mode
- change cube color
- change outline thickness
- change lighting
- switch between flat and smooth shading
- Polish / English UI

## What it is for

This project is meant as a simple reference tool for:
- cube practice
- perspective studies
- form rotation
- basic construction drawing
