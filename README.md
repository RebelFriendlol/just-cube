## 🇬🇧 English Version

### About the Project
**justcube** is a minimalist drawing practice utility that renders an interactive 3D cube in the browser. 

Learning constructive drawing and perspective requires rotating basic geometric primitives in mind and on paper. Launching bulky 3D software (like Blender or Maya) just to reference a cube often disrupts creative workflow. **justcube** solves this by providing instant, frictionless 3D reference directly inside any browser.

### Key Features
- **Interactive 3D Rotation:** Inspect the cube from any angle to analyze foreshortening, vanishing points, and plane orientations.
- **Timed Practice Mode:** Built-in timer for timed sketching drills, quick construction warm-ups, and gesture-like spatial practice.
- **Form & Perspective Study:** An effective visual reference for 1-point, 2-point, and 3-point perspective construction.
- **Single-File Architecture:** The entire application (markup, styling, logic, and 3D rendering) is self-contained in a single file for maximum portability.
- **Offline & Cross-Platform:** Works completely offline without servers, node dependencies, or build tools.

### What It Is Used For
- 📐 **Perspective Studies:** Visualizing how planes compress as viewing angles change.
- 📦 **Cube & Construction Drills:** Quick drawing repetitions to build spatial intuition.
- 🔄 **Mental Rotation Training:** Practicing rotation of 3D forms before committing lines to paper or tablet.
- ⏱️ **Interval Sketching:** Fast-paced drawing sessions using the built-in timer.

### Zero-Install Architecture
- **No `npm install`**
- **No build steps**
- **No external server required**

Everything is bundled into a single `.html` file for user convenience. Simply download and double-click to launch.
